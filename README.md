   # Tic-Tac-Toe  Game

    A responsive and interactive  full-stack Tic-Tac-Toe game developed using HTML,CSS, javascript, nodejs, and mongoDB.
    The application deleviers smooth gameplay, responsive user experience 
    and backend/database integration for scalable game management.
   
 
   ## 🚀 Key Features
   -Interactive two-players gameplay          
   -Responsive and clean user interface      
   -Real-ime win and draw detecation    
   -Restart and reset funtionality    
   -Backend server intergration using Node.js   
   -MongoDB database connectivity   
   -Optimized game logic and user interaction    
   
   ## Tech Stack
   ### Frontend
   -HTML 
   -CSS3  
   -Javascript
   ###  Backend
   -Noode.js  
   ### Database
   -MongoDB   
   ### Deployment Platform
    -Railway
